50 Program Studi Sarjana

Institut Teknologi Bandung (ITB) setiap tahunnya menerima mahasiswa baru untuk menempuh pendidikan di jenjang program sarjana. Namun, ada yang berbeda dengan program sarjana di ITB. Berdasarkan SK Rektor ITB no. 071/SK/K01/PP/2006, setiap mahasiswa baru diterima menjadi mahasiswa fakultas/sekolah terlebih dahulu dan menjalankan program Tahapan Persiapan Bersama (TPB), sebelum akhirnya memilih salah satu program studi serumpun dalam fakultas/sekolah yang sama, pada awal tahun kedua. Penempatan mahasiswa di salah satu program studi serumpun di fakultas/sekolah di ITB, dilakukan oleh ITB sebelum masa perkuliahan tahun kedua dilaksanakan, berdasarkan minat mahasiswa, kapasitas program studi yang bersangkutan, serta tergantung pada prestasi mahasiswa di tahun pertama perkulihan.

53 Program Studi Magister

Hingga saat ini, ITB telah menghasilkan lebih dari 28.883 lulusan magister dari berbagai program studi. Pengelolaan Program Magister ITB berada di bawah Sekolah Pascasarjana ITB dan telah memperoleh akreditasi dari Badan Akreditasi Nasional Perguruan Tinggi (BAN-PT). Dengan berorientasi pada keilmuan dan terapan, Program Magister ITB bertujuan meningkatkan taraf penguasaan ilmu dan kemampuan yang telah diperoleh peserta selama pendidikan tingkat Sarjana sehingga para lulusannya tetap dapat bergerak lincah di bidangnya masing-masing. Program pendidikan Magister dirancang untuk dapat diselesaikan dalam 2 tahun dan bahkan kurang dari 4 semester.

28 Program Studi Doktor

Dengan waktu pendidikan yang ditempuh selama tiga tahun, program Doktor ITB bertujuan menghasilkan lulusan yang mempunyai sikap akademik, mampu meneliti secara mandiri, dan mampu memberi sumbangan berarti kepada khasanah ilmu pengetahuan, ilmu pengetahuan teknik, atau ilmu seni rupa dan humaniora. Selain itu, ITB menawarkan Program Doktor Kemitraan bagi calon mahasiswa dari Institusi Mitra ITB yang telah memiliki kerja sama di bidang pendidikan dengan ITB untuk melanjutkan pendidikan S3 di ITB.

2 Program Profesi

ITB menyelenggarakan Program Profesi Insinyur dan Program Profesi Apoteker.

Program Profesi Apoteker diselenggarakan selama dua semester bagi sarjana (S1) bidang studi Farmasi untuk menjadi Apoteker. Sasaran pendidikan adalah tercapainya kompetensi apoteker sesuai dengan persyaratan nasional (Ikatan Apoteker Indonesia) dan global (The International Pharmaceutical Federation). Sektor kefarmasian yang dapat digarap oleh lulusan program profesi apoteker adalah industri farmasi, pelayanan kefarmasian, regulasi, saintifik, dan sektor lainnya yang berkaitan.

Sedangkan pada Program Profesi Insinyur, ITB menawarkan 18 sub program studi pada 7 fakultas/sekolah melalui jalur Rekognisi Pengalaman Lampau (RPL), serta 1 sub program studi pada 1 fakultas melalui jalur Program Reguler. Program Profesi Insinyur ITB melalui jalur Rekognisi Pengalaman Lampau (RPL) akan dilaksanakan selama 1 semester. Pertemuan tatap muka akan diadakan pada awal, tengah dan akhir semester (akhir minggu) dengan proses tutorial yang dilaksanakan secara online. Sedangkan Program Profesi Insinyur ITB melalui jalur Program Reguler akan dilaksanakan selama 2 semester melalui kegiatan perkuliahan tatap muka dan tutorial di Kampus ITB.
